# SentinelKey — MVP Implementation Roadmap

## Milestone 1: Foundation & Design System (Completed)
- Architecture, threat modeling, database schema, and API contracts defined.
- Strict dark-first cybersecurity command center design language established.
- Server-side Express + Vite full-stack wiring.

## Milestone 2: Core Data Models & Security Engines
- TypeScript types for Users, Posture, Findings, Incidents, Browser Profiles, Breach Hashes.
- Zero-Plaintext k-anonymity client-server protocol implementation.
- Browser Security Center abstraction layer (Chrome, Edge, Brave, Firefox).
- Local Developer Secret Scanner (Client-side regex pattern engine).

## Milestone 3: AI Security Analyst "Sentinel"
- Server-side `@google/genai` integration with `gemini-3.8-flash`.
- Event-grounded prompt engineering with strict hallucination guards.
- Live conversational console with structured action pills.

## Milestone 4: Incident Response Engine ("Secure My Accounts")
- Interactive 10-step containment wizard.
- Real-time containment checklist and verification.
- Exportable Forensic Security Incident Report.

## Milestone 5: Security Graph & Timeline
- Interactive SVG node-link identity topology graph.
- Chronological event-sourcing ledger.

## Milestone 6: Enterprise & Family Modules
- Multi-tenancy RBAC (Owner, Security Admin, Admin, Member, Auditor).
- Privacy-preserving family posture sharing.
- Pricing & subscription tier matrix (Free, Pro, Family, Business).

## Milestone 7: Verification & Security Testing
- Automated unit tests, security tests, XSS/CSRF mitigations, CSP verification.
